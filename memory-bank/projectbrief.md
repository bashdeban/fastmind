## Project Overview

WiseMapping Front End is an integral component of the MindMap Open Source Project, which began in 2010 and underwent significant architectural revitalization in 2021. The project aims to provide a modern, intuitive, and powerful web-based mind mapping solution.

### Core Modules

This repository contains all user interface-related elements, comprising four principal modules:

1. **web2d** - A lightweight abstraction layer over SVG for elegant and efficient chart rendering
2. **mindplot** - Pure vanilla ES6 classes responsible for rendering mind maps and editing functionalities  
3. **editor** - React component wrapper around mindplot
4. **webapp** - A complete React application serving as the cornerstone of the mind map editing experience
